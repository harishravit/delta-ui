## Components purpose

### Comment

    - The box for one full conversation: the main comment and all its replies.

    #### Props and its usage

    | Prop | Type | Default | Values | Use case |
    | --- | --- | --- | --- | --- |
    | `disableBend` | `boolean` | `false` | `true`, `false` | Don't want the curved lines? Set it to `true`. The straight vertical lines stay. |
    | `disableThreads` | `boolean` | `false` | `true`, `false` | Want a clean look with no lines at all? Set it to `true`. Both the curved and straight lines go away. |

    <Callout title="Note" type="info">
    These props only hide the lines. The bend container is still in the DOM, so the tree layout does not break.
    </Callout>

- **Comment** — The root component that wraps a comment and its replies.
- **CommentMain** — The first comment in a conversation, displayed at the top.
- **CommentContent** — Holds the two halves of a comment: the avatar side and the text side. Shared by the main comment and replies.
- **CommentSide** — The left side of a comment, containing the user's avatar and thread line.
- **CommentAvatar** — The frame for the user's photo. The image inside accepts `src` and `alt`. Customize its size using `className`.
- **CommentAvatarImage** — Displays the user's profile image.
- **CommentAvatarBadge** — Displays a small badge at the bottom-right corner of the avatar, typically used for reactions such as ❤️.
  following structure for build avatar component
- **CommentBody** — The right side of a comment, containing the header, message, and footer.
- **CommentHeader** — The top section of a comment, displaying user information and actions.
- **CommentHeaderItem** — Arranges items horizontally in a single line, such as username, handle, date, or action icons.
- **CommentHeaderItemGroup** — Groups header items vertically, such as username and handle on the first line and role on the second.
- **CommentMessageContent** — Groups the comment's media and text together below the header.
- **CommentMessageMedia** — Displays images or GIFs attached to a comment. Accepts `src` and `alt`.
- **CommentMessageText** — Displays the comment text and optionally supports a Read More button for long content.
- **CommentFooter** — The bottom section of a comment, typically containing reply, like, dislike, and share actions.
- **CommentReplyList** — Holds the collection of replies belonging to a comment.
- **CommentReplyItem** — Represents an individual reply, using the same content layout as the main comment.
- **CommentReplyToggle** — Controls the visibility of a comment's replies by expanding or collapsing the reply list.
<Callout title="Note" type="info">

- You don't need to draw or import the thread lines. They come built into the components.
- Every component renders a div, so you can pass any normal div prop like `className`. Two are different:
  - `CommentAvatarImage` renders an img and takes img props.
  - `CommentReplyToggle` renders a button and takes button props.

</Callout>
